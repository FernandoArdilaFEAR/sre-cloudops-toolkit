# SRE & CloudOps Automation Toolkit

A collection of production‑ready automation scripts built for Site Reliability Engineering, Cloud Operations, and Platform roles.  
This repository demonstrates cross‑platform scripting, infrastructure interaction, monitoring, and CI/CD practices.

## 🧰 Tech Stack
- **Python 3** – API health checks, log parsing, cloud resource management (boto3)
- **Bash** – System health reports, SSL certificate monitoring, backup rotation
- **PowerShell 7+** – Windows service management, event log analysis, cross‑platform daemon checks
- **GitHub Actions** – Automated linting and static analysis on every push

## 📂 Repository Structure
- `python/` – Python scripts with full error handling and logging
- `bash/` – Robust shell scripts using best practices
- `powershell/` – Advanced functions, parameter validation, and remoting
- `.github/workflows/` – CI workflows (shellcheck, PSScriptAnalyzer, pylint)

## 🚀 Getting Started
Each script is self‑contained and well‑documented. See comments at the top of each file for usage examples and prerequisites.

## 🎯 Why This Repo?
Built to showcase real‑world SRE/CloudOps skills: observability, incident response, automation, and infrastructure‑as‑code mindset—all in a clean, version‑controlled format.
